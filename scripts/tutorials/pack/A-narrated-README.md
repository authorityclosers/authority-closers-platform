# Sales X-Ray tutorials: narrated videos

Ready-to-share videos with an AI voice (ElevenLabs) and captions burned in. One folder per tutorial.

- `<id>-en.mp4` English (Indian), `<id>-hi.mp4` Hinglish, `<id>-mr.mp4` Marathi-English. 1920x1080, H.264, AAC.
- `<id>-<lang>.srt` the same captions as a file (for YouTube or players that show captions separately).
- Hinglish and Marathi-English also have `-devanagari.srt`.

All names and numbers on screen are made up. Screens may change after this date; ask for a fresh render rather than
editing these files.
