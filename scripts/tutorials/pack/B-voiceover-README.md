# Sales X-Ray tutorials: voice-over kit

For recording your own voice over each tutorial (Dipak, Suyash, or anyone on the team).

## In each tutorial folder

| File                                    | What it is                                                                                                                                                              |
| --------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `<id>-silent.mp4`                       | The finished picture with no sound and no captions. Record over this.                                                                                                   |
| `<id>-script-en.md`, `-hi.md`, `-mr.md` | The script with a start time for every line, what is on screen, and how long the AI voice took. Hinglish and Marathi lines are given in Roman script and in Devanagari. |
| `<id>-cue-sheet.csv`                    | The same as a spreadsheet: one row per shot, all three languages side by side.                                                                                          |
| `<id>-en.srt`, `-hi.srt`, `-mr.srt`     | Captions with timings. Load one in VLC next to the silent video to see where each line falls.                                                                           |

## How to record

1. Open the silent video and the script in your language. Start each line at its time.
2. Each slot fits the longest of the three languages, so there is room to breathe. Do not rush.
3. Talk the way you talk to a new seller on your team: short, friendly, English words for app things.
4. Say the product as "Sales X-Ray" and the score as "Brain four point oh".
5. Record in a quiet room, phone or USB mic 15 cm away, WAV or high-quality M4A. One file per tutorial is fine.
6. Send the recording back; the pipeline lines it up, normalises the level and burns in the captions.

Feel free to change words so they sound like you, but keep UI labels in English exactly as on screen, and never
mention prices, costs or minutes.
