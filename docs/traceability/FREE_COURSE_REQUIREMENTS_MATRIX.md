# Free Course first-slice requirements matrix

Status values are `DECIDED`, `IMPLEMENT`, `VERIFY`, or `CONTROLLED-SOURCE-FIX`. A row cannot be marked verified without linked automated or operational evidence.

## Known controlled-contract omissions

Before G1 passes, controlled docs must add or reconcile:

- auth and session-recovery screen/state identifiers;
- completion and certificate routes, states and component IDs;
- controlled component IDs for the provisional `AuthFlowPage`, `LearnerShell`, `ProgressSummary`, `ActivityShell`, `VideoActivity`, `ChallengeCard`, `CompletionChecklist`, and `CertificateView` names;
- exact API contracts for module activities, activity reads, drafts/evidence, certificates, and free-enrollment provenance;
- certificate and reconciliation/frozen-state entities;
- audit-event classification;
- G1/G2 formal gate definitions and outdated founder-question statuses.
