# Visual exploration gate

Status: **text-only reference-ready; visual/brand approval blocked**.

No raster direction or generated image is included. The controlled UI System
does not approve final brand colors or fonts, and no source-authorized asset
was supplied for an Admin/Instructor product. A generated visual could make
unsupported copy, role, data, publication or provider behavior look approved.
The wireframes therefore express hierarchy, density, responsive reflow and
state placement only.

Before implementation or visual approval, resolve:

- semantic-to-brand token mapping and typefaces (`BLK-VIS-01`);
- the exact role/permission union and approval ownership (`BLK-01`);
- registered routes and masking/export/view-as behavior (`BLK-09`, `BLK-12`);
- assessment and media provider contracts (`BLK-07`, `BLK-08`);
- representative non-sensitive content and accessibility/device evidence.

Reference breakpoints follow the controlled UI System: compact `<600px`,
medium `600–1023px`, wide `>=1024px`, and dense Admin optimization at
`>=1280px`. Breakpoints are layout guidance, not a promise of a native app.
