# Visual direction briefs

Exactly three paired directions were generated for desktop and mobile.
Generated images are references, not implementation authority.

## A — Learning Command Center

Planner-first dashboard with strong next-action hierarchy, a persistent desktop
sidebar, a purpose-built mobile bottom bar, today planning, upcoming practice,
courses, and restrained descriptive activity.

Files:

- `direction-a-command-center-desktop.png`
- `direction-a-command-center-mobile.png`

## B — Skill Journey

Practice-first dashboard with a professional deterministic activity path and
click-first exercises. It borrows rapid feedback and obvious next-action
behavior from language-learning products without reward theater.

Files:

- `direction-b-skill-journey-desktop.png`
- `direction-b-skill-journey-mobile.png`

## C — Content Studio

Media-first dashboard with premium continue-watching, up-next queue, course
library, discovery, saved resources, and restrained analytics.

Files:

- `direction-c-content-studio-desktop.png`
- `direction-c-content-studio-mobile.png`

## Selection dimensions

Each pair is reviewed for IA coverage, desktop/mobile coherence, visual polish,
accessibility, truthful state representation, performance feasibility,
backend/API readiness, reuse of the existing system, and ability to scale to all
required routes. Selection is recorded separately after independent reviews.
