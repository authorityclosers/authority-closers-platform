# Visual exploration gate

Status: **VISUAL GENERATION PENDING**

This package intentionally stops after the behavior/state contract. No raster
visual directions were generated, no Figma/Canva file was created, and no
visual asset is labeled selected or approved. This is allowed by the task
boundary and prevents pixels from inventing routes, copy, data, access,
provider behavior, scoring, or schedule semantics.

Before implementation-facing visual exploration begins, create exactly three
independent desktop/mobile direction pairs in one ideation set, preserve each
original, and review them against:

- task clarity and dominant next action;
- fidelity to the state matrix and three-layer recovery model;
- WCAG 2.2 AA intent, visible focus, non-color state, captions, reflow, and
  comfortable mobile targets;
- light-default / Dark / System behavior without authority changes;
- desktop rail versus compact mobile navigation;
- long copy, 200% zoom, 390px width, safe areas, reduced motion, and keyboard;
- provider/API readiness and implementation risk.

The existing neighboring package at
`../03-visual-exploration/` contains a separate three-direction exploration.
This package does not copy, reclassify, or silently select those assets. If
that exploration is adopted, record the exact selected direction and asset IDs
in this folder’s decision log and manifest, then rerun the affected visual QA.
