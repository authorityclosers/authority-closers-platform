## Structural and traceability gate

- [ ] JSON parses: `04-ai-context/ai-design-context.json` and
  `05-handoff-qa/asset-manifest.json`.
- [ ] CSV parses and contains every minimum schema column from the
  workflow-ui-production artifact schema; each row has a stable `flow_id` and
  `screen_id`.
- [ ] All screen IDs in the matrix appear in the behavioral spec, AI context,
  and PlantUML source; routes match exactly.
- [ ] The manifest declares exactly three visual direction pairs (six PNGs),
  with A/B/C IDs and desktop/mobile viewports.
- [ ] Every visual path exists, its dimensions and SHA-256 match the manifest,
  and visual status is `reference` or `selected` rather than `approved`.
- [ ] PlantUML has one `@startuml`/`@enduml` pair and is editable locally.
- [ ] No file under this package is application source or a deployment change.

## Visual and interaction gate

- [ ] Inspect all six references for legibility, crop, hierarchy, contradictory
  badges, unsupported player details, and mobile bottom-navigation overlap.
- [ ] Direction B remains the selected visual language; no fourth direction is
  generated by blending A/B/C.
- [ ] Replace every raster copy string with controlled content before UI work;
  mock learner names/drafts are not seed data.
- [ ] Use native semantic media/form controls and approved icon assets in a
  later implementation; do not ship PNGs as components.

## Media and assessment gate

- [ ] Approved media provenance, playback-session, resume, watched-interval,
  retention, and policy contracts exist.
- [ ] Caption tracks are approved and tested in supported locales; transcript
  source/timing/visibility are separately approved.
- [ ] Speed, fullscreen, and PiP are feature-detected and tested on desktop
  Chrome, iOS Safari/Home Screen, and Android-compatible PWA. Unsupported
  controls are hidden or honestly labelled.
- [ ] In-video checks pause at authored cues, use stable option IDs, preserve a
  retryable attempt, and provide deterministic authored feedback only.
- [ ] Quiz/test interaction schema, attempt revision, idempotent submit,
  validation, and offline block behavior are proven.
- [ ] AC-SVAL is closed before any official score, evaluator, mastery,
  competency, ranking, or autonomous AI behavior is introduced.
- [ ] Human reviewer assignment, permission, privacy, append-only result,
  correction/supersession, and learner visibility are proven.

## Resilience and accessibility gate

- [ ] Module roadmap supports loading, empty, partial, locked, retry, stale,
  and session-expired states without exposing protected payloads.
- [ ] Reflection/evidence/improve preserve approved local text through dirty,
  saving, saved, conflict, retry, offline, and reauthentication states.
- [ ] Offline renders only allowlisted read cache/local recovery; no canonical
  mutation or hidden background submit occurs. Purge/expiry/tamper/storage
  failure behavior is explicit.
- [ ] Install and update notices are dismissible, safe around dirty work,
  browser/OS mediated, and never described as native apps.
- [ ] Fixed actions and bottom navigation use safe-area insets and reserve
  clearance on iOS Safari/Home Screen and Android PWA.
- [ ] Keyboard order, visible focus, labels, fieldsets/legends, live regions,
  error association, focus return, Escape, and screen-reader semantics pass.
- [ ] 200% text/400% page zoom and 320 CSS px reflow retain content/function;
  no two-axis scrolling for ordinary text/actions.
- [ ] Touch targets aim for 44 CSS px; drag interactions have select/tap
  alternatives; hover is never the only disclosure.
- [ ] Portrait/landscape, background/foreground, reduced motion, forced colors,
  captions, and player focus are verified on real target browsers/devices.
