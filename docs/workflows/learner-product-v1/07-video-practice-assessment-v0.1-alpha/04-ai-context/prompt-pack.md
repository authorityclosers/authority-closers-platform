# Visual prompt pack

The package's visual set is intentionally limited to exactly three independent
paired directions. These prompts are retained for reproducibility and future
iteration; no new image generation or runtime implementation is claimed here.

## Shared constraints for every direction

Create one desktop frame at `1440 × 1024` and one mobile frame at `390 × 844`
for an enrolled Authority Closers learner. Use the existing learner visual
language: deep navy ink, cobalt action, pale blue-gray canvas, white task
surface, thin cool-gray dividers, restrained radii, readable sans-serif
fallback. Show one semantic module roadmap and the learning-loop labels. Use
real text placeholders only as clearly illustrative reference copy.

Do not add marketplace, ratings, recommendations, social, gamification,
leaderboards, payment, billing, notifications, search, fake player controls,
fabricated captions/transcript, duration, upload limits, reviewer identity,
score, mastery, AI, certificate, real-call recording, or native-app framing.
Never use a raster as the product UI. Any media/caption/transcript/resume state
must be marked conditional on the approved contract.

## Direction A — Guided Practice Canvas

Task-first, practice-led composition. Put the current reflection or quiz task
in the dominant column, keep a concise ordered roadmap adjacent on desktop, and
collapse it behind `View module path` on mobile. Keep the five loop stages
visible, use text plus icon for current/locked state, and show a truthful
`media not ready` path whenever Watch is not canonically available. Treat any
transcript and Watch-complete visual as conditional annotations only.

## Direction B — Momentum Workshop (selected)

Create a calm evidence-making workspace with one current task, one dominant
next action, and a visible five-stage roadmap. Desktop is a task column plus a
roadmap rail. Mobile is a single task stack with safe-area-aware bottom
navigation and a `View module path` disclosure. Show explicit `Unsaved`,
`Saving`, `All changes saved`, `Conflict`, `Offline — not synced`, and
`Awaiting human review` states in companion specs, not invented badges in the
happy-path image. Keep Watch media-gated until the media contract is approved.

## Direction C — Studio Ledger Player

Media-first hierarchy for a future approved player: lesson context on one side,
reflection/evidence ledger on the other, and one next action. Use the player,
captions/transcript, resume, speed, fullscreen, and PiP regions only as
capability placeholders with no provider, duration, or source claims. Keep the
mobile composition linear and readable. Any utility bell, duration, transcript
copy, or completion text from a source fixture is superseded unless its
canonical contract is proven.

## Correction protocol

When a visual conflicts with the state matrix, remove the unsupported visual
claim and retain the original under a clearly marked superseded/reference
record. Do not blend the three directions into a fourth visual system. Record
the reason in `03-visual-exploration/selection-decision.md` and
`05-handoff-qa/decision-log.md`.
