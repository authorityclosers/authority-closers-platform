# Visual selection and gate

Date: 2026-09-03
Family: video → practice → assessment → evidence → review → improve
Status: **Direction B selected as a reference; not production-approved**

## Evaluation

| Lens | A — Guided Practice Canvas | B — Momentum Workshop | C — Studio Ledger Player |
| --- | --- | --- | --- |
| Task clarity | strong reflection focus | **strongest one-task/one-next-action pairing** | strong lesson-to-ledger focus |
| Behavioral fidelity | conditional transcript/Watch fixture | **strongest honest blocked-media and recovery framing** | conditional media metadata and utility controls |
| Recovery quality | specified outside frame | **clearest mobile/desktop continuity** | good ledger continuity; sticky-action risk |
| Accessibility | semantic fallback required for dense stepper | **best current/next/locked text hierarchy; browser proof still required** | dense mobile stepper and fine borders need proof |
| Extensibility | practice-first; player treatment secondary | **stable roadmap + task shell can host all activity kinds** | player-first; future media contract required |
| Implementation risk | transcript and conditional completion must be removed/guarded | **moderate; canonical authorization/revision gates remain explicit** | highest; duration/transcript/notification details are unsupported |
| Decision | reserve for practice comparison | **selected visual language** | reserve for approved media exploration |

## Decision

Select Direction B after the corrected Momentum Workshop pair. It gives the
learner a stable current task and next action across desktop Chrome and the
responsive PWA while preserving a truthful blocked-media state. Direction A is
retained as a practice-proportions reference. Direction C is retained as a
media-layout reserve only; its raw copy and controls are superseded by the
capability gates in the behavioral spec.

## Selection gates

The selected visual direction cannot be promoted until all of the following
are evidenced:

1. approved media source/provenance, caption tracks, transcript projection, and
   playback-session/resume policy;
2. browser capability checks for speed, fullscreen, and PiP on desktop Chrome,
   iOS Safari/Home Screen, and Android-compatible PWA;
3. authored interaction schema and deterministic feedback for knowledge checks
   and quiz/test;
4. human reviewer assignment, privacy, append-only result, and learner
   visibility contract;
5. draft/evidence revisions, offline local recovery, conflict handling, and
   no offline canonical writes;
6. keyboard/focus, 200%/400% zoom, 320px reflow, touch, safe-area,
   orientation, background, update, install, and auth-expiry evidence.
