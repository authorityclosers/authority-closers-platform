# Exactly three visual directions

The package contains exactly three independent desktop/mobile direction pairs.
The six PNGs are generated visual references copied from the preserved
workstream artifacts; they are not application UI, source-of-truth content, or
runtime evidence. No fourth direction is implied.

## Direction A — Guided Practice Canvas

Files:

- [`direction-a-guided-practice-canvas-desktop-1440x1024.png`](direction-a-guided-practice-canvas-desktop-1440x1024.png)
- [`direction-a-guided-practice-canvas-mobile-390x844.png`](direction-a-guided-practice-canvas-mobile-390x844.png)

Current task dominates the page, with a concise course outline and an
activity loop across the top. It is strong for reflection and low-typing
practice. The raster shows a transcript and a completed Watch state only as a
conditional fixture; hide them when the media/content gates are not met.

## Direction B — Momentum Workshop (selected)

Files:

- [`direction-b-momentum-workshop-desktop-1440x1024.png`](direction-b-momentum-workshop-desktop-1440x1024.png)
- [`direction-b-momentum-workshop-mobile-390x844.png`](direction-b-momentum-workshop-mobile-390x844.png)

One current task, one dominant action, and a visible five-stage loop provide
the clearest cross-breakpoint continuity. Desktop uses a task column plus
roadmap; mobile preserves the loop and moves the full path behind a labelled
disclosure. Watch is visibly media-gated and the selected pair avoids fake
player metadata. This direction is the selected visual language, not approval
of the underlying media or review capabilities.

## Direction C — Studio Ledger Player

Files:

- [`direction-c-studio-ledger-player-desktop-1440x1024.png`](direction-c-studio-ledger-player-desktop-1440x1024.png)
- [`direction-c-studio-ledger-player-mobile-390x844.png`](direction-c-studio-ledger-player-mobile-390x844.png)

Media-first hierarchy places lesson context beside a writing ledger. It is a
useful reserve for a future approved player, but the generated raster contains
conditional/unsupported details such as duration, transcript copy, and an
illustrative utility control. Those details must not be implemented without a
source, policy, and runtime gate.

## Shared visual rules

- Existing Authority Closers learner tokens remain primary: deep navy ink,
  cobalt action, white task surface, cool-gray dividers, restrained radii, and
  readable sans-serif fallback.
- One semantic ordered roadmap is authoritative; duplicate visual summaries
  are presentation-only.
- Use real semantic controls and icons in implementation. Never ship a raster
  as the UI or copy its mock learner text into seeded data.
- Loading, locked, blocked-media, offline/stale, conflict, session-expired,
  review-waiting, and completed states come from the state matrix, not from
  pixels.
