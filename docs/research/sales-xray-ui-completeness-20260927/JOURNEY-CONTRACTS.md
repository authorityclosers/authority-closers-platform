## Acceptance and open decisions

For every edge above, collect a fixture identity, initiating role, initial canonical state, input, observed response, resulting state and focus/return position. Test desktop and mobile where composition differs; include keyboard, reduced motion, zoom and short-height audio-dock overlap. These checks are **required evidence still to gather**, not tests performed by this research lane.

Before claiming these journeys complete, resolve:

1. **Updated product authority:** which current controlled document supersedes the excluded old BRD? Existing guest, profile, consent and access behaviour remains descriptive until reconciled.
2. **Reviewer identity:** preserve or intentionally supersede the dedicated reviewer service through a reviewed contract. Do not infer Academy sign-in from retained components. Final adjudication owner/API is an explicit gap.
3. **Recovery after document loss:** local File and in-memory consent/start intent do not survive reload. Specify server reconciliation and any re-selection/re-consent needed; no invented persistent resume.
4. **Navigation ownership:** resolve mounted ReportModes versus ReportExplorer/legacy paths through explicit entry tests; a proposed universal Back rule cannot override their different source logic unnoticed.
5. **Source revocation and drafts:** define permitted residual draft/history handling under updated retention/access rules. Displaying saved proposal history does not authorize retaining erased source content.
