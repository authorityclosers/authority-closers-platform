## Findings retained after local review

- Connected, authorized and recoverable journeys are the useful completion unit. Do not dispatch all240 pending slots solely to satisfy the count.
- Sign-in, reviewer invitation/acceptance/assignment, pre-admission upload and multiple app-entry contexts need more explicit coverage.
- Source quotes, surrounding context, explanation support, report revisions and chart meanings require separate checks. Correct binding is not necessarily adequate semantic support.
- Settings need scope, effective revision, actor, pending/conflict/recovery and execution consequences. A notification failure is separate from a failed grant or analysis.
- Retain one audio controller and explicit excerpt/context/full-call modes. A modal needs operable controls inside its interaction scope without a second audio engine.
- Prototypes, content stress, keyboard/screen-reader/playback evidence, canonical state checks and user comprehension are necessary beyond raster references.
- Reuse the existing stack and evaluate new primitives narrowly. Do not add a second design system to imitate a visual theme.
