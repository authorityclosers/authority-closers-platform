# Obsidian visual system

The vault graph uses hierarchical `ac/*` tags as machine-readable color groups. Sources are purple, journeys amber, visual boards pink, screens cyan, routes blue, APIs teal, decisions magenta, implementations green, gates red, evidence yellow, limitations rose, workstreams orange, and meta nodes slate.

Graph defaults in `.obsidian/graph.json` show arrows, hide unresolved/orphan/attachment clutter, and retain only existing notes. Tags remain properties rather than separate graph dots.

- visual boards: [[VJB-MOC-001-visual-journey-boards]].
- conventions: [[META-001-node-taxonomy]] and [[META-002-relationship-legend]].
- evidence boundary: color represents node type, never completion or live proof.
