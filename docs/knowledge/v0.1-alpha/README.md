## Evidence rule

`controlled` > `repository interpretation` > `implementation candidate` > `historical exact-release evidence` for authority. Historical evidence remains valid for its named SHA; it does not prove the current dirty worktree. Analytics and visual references never become canonical access, progress, payment, or deployment state.
