## Offline fast check

`scripts/ci/ac_fast_check.py` accepts a clean, locally available commit and an
absolute receipt path outside the checkout. It selects changed-module Ruff and
incremental mypy, installed Prettier/cached ESLint/incremental TypeScript for
affected apps and workspace consumers, related Vitest, and capped pytest files
from a transitive static import graph. It performs no fetches or installs.

Default limits are 300 seconds wall, 180 process CPU seconds and twelve pytest
files. Directly changed tests take priority. Receipts record omissions and
unmapped imports as partial coverage, attest source before and after execution,
suppress child output/environment, and clean up observed descendants. Shared
package tests run in their package directory and direct runs must collect tests.

Claude owns installation of the capped service and the non-required `ac-ci/fast`
status. The service must deny external egress while allowing the lane's loopback
PostgreSQL, enforce cgroup limits and clean up all service processes. Required
GitHub check names and hosted runners remain unchanged.
