## Offline verification

```bash
uv run --frozen pytest tests/infra/test_ac_usage_guard.py -q
uv run --frozen ruff format --check packages/python tests
uv run --frozen ruff check packages/python tests
uv run --frozen mypy packages/python
```

Five tests pass. The refresh-required regression, run against a private scratch
copy of the exact original, fails twice with `NameError: name 'subprocess' is not
defined` at line 144 (success/failure subprocess result cases). Both cases pass
with the import. Valid-token and hourly-cooldown cases also pass. Removing the
single import restores the original SHA-256.

The tests mock credential reads, time, subprocess and logging, and deny other
`Path.read_text` calls and HTTP requests. They assert the unchanged subscription
CLI command, API-key environment unsets, model, timeouts, refresh timestamp and
unrelated state. No real refresh, auth-file read, provider request, guard CLI,
database access or host/service change was performed. The source stays outside
the existing formatter targets, preserving its reviewed byte provenance.
