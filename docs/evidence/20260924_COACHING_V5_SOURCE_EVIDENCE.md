## Problem and change

An actual old/new fictional long-call comparison found that the v4 candidate's eight skill notes remained thin, and exact quotations did not prevent unsupported causal interpretations. This is a quality failure, not proof of improvement over the baseline.

The successor `coaching-v5` requires all eight dimensions and separate transcript evidence for observed/conflicted dimensions. Evidence is resolved against native transcript segments and validated again when reading canonical reports. Rubric citations remain separate. Legacy provider parsing, v4 pack identity, and historical report serialization remain compatible; legacy reports omit the new optional field, while v5 unknown dimensions may retain an explicit empty evidence array.

The versioned prompt asks for behavior, buyer relevance, limits, and a useful keep/change action. It preserves conditional permission, commercial authorization, corrections, and a valid stop outcome in practice. These instructions do not constitute a semantic quality guarantee.

Analysis settings/CLI, frozen processing plans, retained recovery and Gemini structured adapters explicitly recognize v5. A request cannot silently downgrade the new structured schema. Migration 0047 permits the successor without changing saved settings; activation remains an explicit append-only settings operation. Provider/output limits are unchanged.

## Release limits

No v5 provider report has been generated by this change. No paid request or production activation was performed. This is bounded single-call coaching, not full Brain 3 learner history, persistent focus, official scoring or cross-call analysis. Existing accepted reports must remain traceable and must not be silently regenerated.
